## Gate

**72 suites, 2,905 assertions** on `main`, green. `npm ci` is required before `npm run test:math`:
the gate stopped being dependency-free when suites began reaching `@capacitor/*` through the
notification planner. `.github/workflows/math-lock.yml` runs on every push and pull request to
`main`, and **`math` is already a required status check** on `main` (verified through the GitHub
API, not assumed). Force pushes and deletions are blocked. Two settings are still off and are the
founder's call: *require branches to be up to date before merging* and *include administrators*.
